# Token Flow 🚀

LLM 流量监控与上下文优化系统

[![Python 3.9+](https://img.shields.io/badge/python-3.9+-blue.svg)](https://www.python.org/downloads/)
[![FastAPI](https://img.shields.io/badge/FastAPI-009688.svg?logo=fastapi&logoColor=white)](https://fastapi.tiangolo.com/)
[![React](https://img.shields.io/badge/React-20232A?logo=react&logoColor=61DAFB)](https://react.dev/)

## 功能特性

- 📊 **流量监控**: 实时监控 API 调用、Token 消耗和成本
- 🔍 **上下文模式识别**: 自动检测 Full Context / Sliding Window / Summarization / RAG 等模式
- 💡 **智能建议**: 识别低效使用并提供具体优化方案
- 💰 **节省分析**: 量化当前节省和潜在优化空间
- 🎨 **OpenAI 风格看板**: 直观的管理界面
- 🔒 **私有化部署**: 数据本地存储，支持 SQLite/PostgreSQL

## 快速开始

### 1. 克隆项目

```bash
git clone <repo-url>
cd token_flow
```

### 2. 启动后端

```bash
cd backend
conda create -n tokenflow python=3.11 -y
conda activate tokenflow
pip install -r requirements.txt
python run.py
```

### 3. 启动前端

```bash
cd ../frontend
npm install
npm run dev
```

### 4. 访问看板

打开 http://localhost:5173

## 使用代理

```python
import openai

client = openai.OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="your-openai-key",
    default_headers={"X-API-Key": "your-tokenflow-key-id"}
)
```

## 检测的上下文模式

| 模式 | 说明 | 检测信号 |
|-----|------|---------|
| Full Context | 全量历史保留 | 消息数>20, token快速增长 |
| Sliding Window | 滑动窗口 | 消息数稳定, 窗口大小检测 |
| Summarization | 对话总结 | 首条消息特征, 长度分布 |
| RAG | 检索增强 | 检索命中率 (预留) |
| Hierarchical | 分层内存 | MemGPT 风格 (预留) |
