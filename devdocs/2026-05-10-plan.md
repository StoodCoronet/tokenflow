## 最近完成的变更（2026-05-07 ~ 2026-05-18）

### UI 增强
1. **URL hash 持久化** — 刷新页面后保留当前 tab（`#providers`, `#sessions`, `#analysis`, `#settings`）
2. **Analysis 默认时间范围** — 从 24h 改为 7d
3. **Token 格式化** — `>=1M` 显示 `X.XM`，`>=1K` 显示 `X.XK`
4. **饼图字体** — 改为 `system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif`
5. **配色方案** — 保留 default 配色，移除临时切换按钮
6. **KeyListTable 可点击引导** — 新增 "Click a row to view details" 提示 + 每行 "View →" hover 标签
7. **Providers 卡片增强** — recharts `AreaChart` 平滑曲线趋势图 + token 总量 + 预估成本，时间范围 `all`（90 天）
8. **Providers 详情面板内联** — 选中 Provider 后详情直接渲染在卡片下方（`col-span-full`），不再跳转到页面底部
9. **Providers 密钥安全** — Token Flow key ID 部分掩码（`8chars...4chars`）+ Copy 按钮

### Token 计费基础
1. `AppConfig` 新增 `Pricing?: Record<string, ModelPricing>`
2. 默认价格表：gpt-4o, gpt-4o-mini, claude-3-5-sonnet, claude-3-opus, deepseek-chat, deepseek-coder, gemini-1.5-pro, gemini-1.5-flash
3. `proxy/handler.ts` 每次请求后计算 `estimated_cost`
4. `stats_aggregates` 和 `request_logs` 均存储 `estimated_cost`
5. Analysis OverviewCards 新增 "Est. Cost" 卡片
6. Providers 卡片显示预估成本

### Analysis Dashboard
1. **TrendChart 颜色-Key 映射修复** — 隐藏/显示 Key 后颜色保持一致（基于 `allKeyNames` 原始索引，不再随 `activeKeys` 变化）

### Studio-sim 增强
1. **Live 模式** — `--live --duration <min> --users <n>` 持续运行模拟
2. **3 种用户 Persona** — Coder（高频/代码）、ChatUser（中频/对话）、Researcher（低频/深度研究）
3. **Heartbeat** — `--heartbeat --heartbeat-interval <sec>` 模拟用户间发送轻量 keepalive 消息
4. **启动时 `cleanupOldStats()`** — 90 天旧数据自动清理
5. **删除 fast 模式** — 强制走完整 HTTP proxy 链路，大规模测试不再直接 INSERT
6. **新增 `--db <path>`** — 可指定主数据库路径，模拟结束后自动将 providers 同步到用户 `config.json5`

## 换机后快速恢复

```bash
# 1. 克隆并切分支
git checkout feat/typescript

# 2. 安装依赖
pnpm install

# 3. 构建 workspace 包
pnpm build

# 4. 启动开发环境（三个终端）
pnpm dev:server   # localhost:40001
pnpm dev:ui       # localhost:40002
pnpm dev:docs     # localhost:40003

# 5. 验证
pnpm test         # 90 passed
pnpm build        # server + ui + docs
```

### 生成模拟数据用于 UI 调试

```bash
# 高并发压力测试（走完整 proxy 链路）
npx tsx tests/simulation/studio-sim.ts --requests 2000 --concurrency 50

# 写入主数据库并同步 providers 到 config（供 UI 调试）
npx tsx tests/simulation/studio-sim.ts --requests 1000 --days 7 --db ~/.tokenflow/tokenflow.db

# 实时模拟：10 人团队，心跳保活，持续 30 分钟
npx tsx tests/simulation/studio-sim.ts --live --duration 30 --users 10 --heartbeat

# 实时模拟 + 保持 server 运行（配合 UI 查看 Dashboard）
npx tsx tests/simulation/studio-sim.ts --live --duration 60 --users 10 --keep
# 另开终端: pnpm dev:ui
```
