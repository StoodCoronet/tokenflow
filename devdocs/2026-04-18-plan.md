### 3B — Sessions 页面重设计

> 详细 spec: devdocs/2026-04-18-sessions-page-spec.md

**现状**: 简单只读表格
**目标**: 双展示模式 + 卡片 + 颜色指示器 + 筛选 + 对话预览

#### 页面结构

```
Sessions 页面内部:
  Tab 1: 概览 (Overview) — 统计卡片 + 模式分布图
  Tab 2: Session 列表 — 卡片视图 + 筛选器 + 无限滚动
  点击卡片 → Session 详情页
```

#### 3B.1 概览 Tab
- [ ] 统计卡片: 总 session 数、总 token、平均效率、活跃 session 数
- [ ] 模式分布图: 环形图或柱状图 (recharts)
- 文件: `packages/ui/src/components/SessionsOverview.tsx`

#### 3B.2 Session 列表 — 卡片视图
- [ ] 双展示模式切换:
  - **Session 为单位**（主）: 找低效 session
  - **Key 为单位**（次）: 按 key 分组管理
- [ ] 卡片设计:
  - 折叠态: 状态指示灯 + 消息数 + token 总量 + 模式 + 效率评分 + key 名称
  - 展开态: prompt 趋势 + 警告/建议 + 可折叠对话预览（最近 5 条，role + 前 50 字）
- [ ] 颜色编码:
  - 效率: A=绿, B=黄绿, C=黄, D=红
  - Token: 背景色深浅或侧边色条
- [ ] Session 状态: Active (5分钟内有请求, 绿点) / Idle (灰点)
- 文件: `packages/ui/src/components/SessionCard.tsx`, `KeyGroupView.tsx`

#### 3B.3 筛选器
- [ ] 时间范围: 快捷预设 (今天/7天/30天) + 自定义范围
- [ ] API Key: 下拉选择
- [ ] 上下文模式: full_context / sliding_window / summarization
- [ ] 效率评分区间: 滑块或输入框
- [ ] 排序: 默认时间降序，可切换效率升序/token降序
- 文件: `packages/ui/src/components/SessionFilters.tsx`

#### 3B.4 分页
- [ ] 无限滚动加载
- 需 API 支持分页参数 (offset/limit)

#### 3B.5 Session 详情页
- [ ] 完整 request_logs 表格
- [ ] Token 趋势图 (recharts AreaChart, prompt vs completion 双线)
- [ ] 分析报告: 检测模式 + 效率评分 + 建议
- [ ] "返回列表"导航
- 文件: `packages/ui/src/components/SessionDetail.tsx`

#### 3B.6 后端 API 扩展
- [ ] `GET /api/sessions` 增加: 分页参数, 筛选参数 (key_id, pattern, efficiency range, time range)
- [ ] `GET /api/sessions/:id` 返回: 最近 5 条消息内容 (role + content 摘要)
- [ ] `GET /api/sessions/stats` 新增: 统计概览数据 (模式分布、总量等)
- 文件: `packages/server/src/routes/index.ts`

#### 完成标志
- [ ] 概览 Tab 显示统计 + 模式分布图
- [ ] Session 卡片列表，带颜色编码和展开/折叠
- [ ] 筛选器全部可用
- [ ] Key-centric 视图可切换
- [ ] 点击卡片进入详情页，显示日志 + 图表 + 分析
- [ ] 无限滚动正常工作
