# Token Flow 部署教程

## 系统要求

- **操作系统**: Linux/macOS/Windows (WSL2)
- **Python**: 3.9+
- **Node.js**: 18+
- **Conda**: Miniconda 或 Anaconda
- **Docker**: 20.10+ (可选，用于运行数据库)

## 快速开始

### 1. 克隆/下载项目

```bash
cd /path/to/token_flow
```

### 2. 启动数据库 (可选)

如果你需要使用 PostgreSQL 而不是 SQLite，启动 Docker 数据库：

```bash
docker-compose up -d
```

> 默认使用 SQLite，无需 Docker。SQLite 数据保存在 `backend/token_flow.db`

### 3. 配置后端

#### 3.1 创建 Conda 环境

```bash
cd backend

# 创建环境
conda create -n tokenflow python=3.11 -y

# 激活环境
conda activate tokenflow

# 安装依赖
pip install -r requirements.txt
```

#### 3.2 配置环境变量

```bash
# 复制示例配置
cp .env.example .env

# 编辑 .env 文件 (可选)
# 默认配置使用 SQLite，通常无需修改
```

默认配置：
- 数据库: SQLite (`sqlite+aiosqlite:///./token_flow.db`)
- 后端端口: 40001
- 前端端口: 40002

### 4. 启动后端

```bash
# 确保在 backend 目录且 conda 环境已激活
conda activate tokenflow

# 方式 1: 使用 run.py
python run.py

# 方式 2: 直接使用 uvicorn
uvicorn app.main:app --reload --host 0.0.0.0 --port 40001
```

后端启动后访问：
- API 文档: http://localhost:40001/docs
- 健康检查: http://localhost:40001/health

### 5. 配置前端

```bash
cd ../frontend

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

前端启动后访问：
- 看板: http://localhost:40002

### 6. 验证安装

1. 打开 http://localhost:40002 看板
2. 在 API Keys 页面添加你的 OpenAI API Key
3. 使用代理地址发送请求测试

## 使用代理

### Python 示例

```python
import openai

# 配置使用 Token Flow 代理
openai.api_base = "http://localhost:40001/v1"
openai.api_key = "your-upstream-api-key"

# 添加 Token Flow API Key ID 到请求头
import httpx

client = openai.OpenAI(
    base_url="http://localhost:40001/v1",
    api_key="your-upstream-api-key",  # OpenAI key
    default_headers={"X-API-Key": "your-tokenflow-key-id"}
)

response = client.chat.completions.create(
    model="gpt-3.5-turbo",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Hello!"}
    ],
    session_id="conversation-001"  # 可选，用于会话追踪
)
```

### curl 示例

```bash
curl http://localhost:40001/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "X-API-Key: your-tokenflow-key-id" \
  -d '{
    "model": "gpt-3.5-turbo",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Hello!"}
    ],
    "session_id": "conversation-001"
  }'
```

## 生产部署

### 使用 Gunicorn + Uvicorn

```bash
cd backend
conda activate tokenflow

# 安装 gunicorn
pip install gunicorn

# 启动 (4 工作进程)
gunicorn app.main:app -w 4 -k uvicorn.workers.UvicornWorker --bind 0.0.0.0:40001
```

### 使用 systemd 服务

创建 `/etc/systemd/system/tokenflow.service`：

```ini
[Unit]
Description=Token Flow Backend
After=network.target

[Service]
Type=simple
User=your-user
WorkingDirectory=/path/to/token_flow/backend
Environment="PATH=/path/to/conda/envs/tokenflow/bin"
ExecStart=/path/to/conda/envs/tokenflow/bin/uvicorn app.main:app --host 0.0.0.0 --port 40001
Restart=always

[Install]
WantedBy=multi-user.target
```

启用服务：

```bash
sudo systemctl daemon-reload
sudo systemctl enable tokenflow
sudo systemctl start tokenflow
sudo systemctl status tokenflow
```

### 前端构建

```bash
cd frontend
npm install
npm run build

# 构建产物在 dist/ 目录，可用 nginx 托管
```

### Nginx 配置示例

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/token_flow/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # 后端 API 代理
    location /api/ {
        proxy_pass http://localhost:40001/api/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }

    location /v1/ {
        proxy_pass http://localhost:40001/v1/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

## 配置说明

### 环境变量

| 变量 | 默认值 | 说明 |
|-----|-------|------|
| `DATABASE_URL` | `sqlite+aiosqlite:///./token_flow.db` | 数据库连接 |
| `SECRET_KEY` | `your-secret-key` | JWT 密钥 |
| `PROXY_HOST` | `0.0.0.0` | 代理监听地址 |
| `PROXY_PORT` | `40001` | 代理端口 |
| `LOG_LEVEL` | `INFO` | 日志级别 |

### 切换到 PostgreSQL

1. 修改 `.env`：
```env
DATABASE_URL=postgresql+asyncpg://tokenflow:tokenflow@localhost:5432/tokenflow
```

2. 安装依赖：
```bash
pip install asyncpg
```

3. 启动 PostgreSQL：
```bash
docker-compose up -d db
```

## 故障排除

### 端口冲突

```bash
# 检查端口占用
lsof -i :40001
lsof -i :40002

# 更换端口
# 后端: python run.py --port 40001
# 前端: npm run dev -- --port 40002
```

### 数据库权限

```bash
# 确保有写入权限
chmod 755 backend/
```

### CORS 错误

编辑 `backend/app/main.py`：
```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:40002", "http://your-frontend-domain"],
    ...
)
```

### Conda 环境激活失败

```bash
# 初始化 shell
conda init bash  # 或 zsh
source ~/.bashrc  # 或 ~/.zshrc
```

## 更新

```bash
# 后端
cd backend
conda activate tokenflow
pip install -r requirements.txt --upgrade

# 前端
cd ../frontend
npm update
```

## 卸载

```bash
# 停止服务
sudo systemctl stop tokenflow  # 如果使用 systemd
pkill -f uvicorn

# 删除 Conda 环境
conda deactivate
conda remove -n tokenflow --all

# 删除数据库 (可选)
rm backend/token_flow.db

# 停止 Docker 容器
docker-compose down -v
```
